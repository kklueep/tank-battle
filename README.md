# 坦克大战 · Battle City

一个纯 HTML + Canvas 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖。

## 🎮 玩法

- **目标**：摧毁所有敌人坦克（每关 20 辆），同时保卫下方的基地（老鹰）。
- **基地被摧毁** 或 **玩家生命耗尽** 则游戏结束。

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动坦克 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |

## ✨ 特性

- 经典地图元素：砖墙（可摧毁）、钢墙（需满级火力）、水域、树林（遮挡）、基地
- 敌人 AI：随机移动 + 自动开火
- 道具系统：闪光的敌人会掉落道具
  - ⭐ 火力升级（可摧毁钢墙）
  - ➕ 额外生命
  - ⛨ 护盾（8 秒无敌）
  - ❄ 冰冻（冻结所有敌人）
- 分数、生命、关卡、剩余敌人数 HUD
- WebAudio 合成音效（无外部音频文件）
- 3 个关卡

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管（如 GitHub Pages）。
